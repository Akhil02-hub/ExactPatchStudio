## ✨ What this is

ExactPatchStudio is a self-contained, single-file wedding invitation that runs entirely in the browser. No build step, no framework, no server — just open `ExactPatchStudio.html` and it works.

It was built as a demonstration of what a modern, emotional, richly-animated digital invitation *can* feel like — interactive, cinematic, and personal.

---

## 🎬 Features

- **Envelope reveal** — opens with a wax seal you tap to unfold
- **Interactive scratch card** — reveal the wedding date by scratching the gold foil
- **Live countdown** — days / hours / minutes / seconds until the big day
- **3D tilted invitation card** — follows your cursor
- **Parallax scroll** — petals, gradients, and gallery images drift as you scroll
- **Animated timeline** — the couple's story, decade by decade
- **Gallery with lightbox** — full-screen image viewer with keyboard navigation
- **RSVP form** — backed by Formspree (plug your own endpoint)
- **Personalization** — `?name=Guest` parameter greets each guest by name
- **Ambient music** — soft, off by default, opt-in
- **Reduced-motion safe** — respects `prefers-reduced-motion`
- **Mobile-first responsive** — designed 320px up to 1440px+
